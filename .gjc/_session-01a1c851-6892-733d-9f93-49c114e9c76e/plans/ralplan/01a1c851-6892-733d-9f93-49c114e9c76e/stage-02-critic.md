## 대표 구현 경로의 사전 시뮬레이션
- **입력·시간 경계:** 승인 후 main의 keydown/keyup을 시간 인자와 함께 순수 logic에 전달한다. 최초 누름은 즉시 논리 좌표를 변경하고 t+119ms 새 방향 입력은 소비하되 이동 큐에 남기지 않는다. t+120ms 이후라도 이미 유지 중인 키는 이동하지 않고 해제·새 누름만 수락한다. S07/S11이 필요한 상태 구분과 경계 기대값을 제공한다.
- **승인 데이터 연결:** 먼저 승인된 5장 격자를 levels에 복사하고 시작점을 범례에서 도출한다. sprites는 승인된 8색과 인덱스 배열만 사용한다. 아직 값이 없으므로 이 경로의 현재 결론은 구현 차단이지 임시 데이터 생성이 아니다. 벽·경계에서 좌표 유지 외의 시각·잠금 기대값은 M02 승인 뒤 정한다.
- **표시·완료 확인:** 향후 index/main은 240×192 논리 Canvas에서 16px 상단 공간을 두고 맵을 표시하며 CSS 720×576 고정을 유지한다. 자동 검증과 승인 데이터 대조 뒤 사람이 실제 맵으로 단타·길게 누름·이동 중 입력·막힘을 확인하고 실제 9장 번호로 기록한다. S09~S11은 이 경로에 관찰 가능한 기준을 제공한다.

위 시뮬레이션은 문서와 향후 책임 설계의 검토이며 코드 실행·제품 동작 검증 결과가 아니다.
