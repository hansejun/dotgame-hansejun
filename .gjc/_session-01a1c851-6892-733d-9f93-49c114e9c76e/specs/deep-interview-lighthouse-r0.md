## Goal
등대지기가 폭풍 전에 바다 유령을 피해 모든 등불을 켜는 3레벨 단일 화면 도트 게임의 확정 규칙과 수치를 10장 구조의 GAME_DESIGN.md v0를 위한 R0 명세로 정리하고, 맵·팔레트·기능 상세는 합의된 R1~R3에서 보완하며 각 구현은 별도의 계획 승인과 사람의 브라우저 확인을 거친다.

이 문서는 인터뷰 명세다. GAME_DESIGN.md는 아직 작성하지 않았다. R0 전체 완료에는 GAME_DESIGN.md v0 작성 후 사람의 기획 검토가 필요하다. 다음 단계의 승인 범위는 먼저 R0 문서화로 제한한다. R1 구현은 별도 계획 승인이 필요하다.

## Constraints

- GAME_DESIGN.md가 구현의 유일한 기준. 기획이 모호하면 먼저 고쳐 사람에게 보여 준다. 확정 숫자를 코드에서 임의로 바꾸지 않는다.
- src/logic.js는 canvas를 모르는 순수 상태 변환 함수. 문자 격자는 src/levels.js에 그대로 복사하며 좌표를 따로 적지 않는다.
- src/sprites.js의 팔레트 인덱스 배열로 스프라이트 작성. 색은 기획서 6장의 8색 hex만 사용. 색값과 배열은 지금 확정하지 않는다.
- 영문 식별자. UI 문구는 src/strings.js 한 곳에서 관리한다.
- 조작은 방향키 4개와 Enter뿐이다.
- 맵은 모두 15×11칸, 타일 16px. 맵 위 HUD는 높이 16px이며 시간·점수·남은 등불 수를 표시한다.
- 논리 크기 240×192px, CSS 고정 3배 표시 720×576px. 반응형 확대 없음.

## 확정 규칙 — 후속 라운드 기획의 입력
### 이동·접촉
- 방향키 한 번 누름에 정확히 한 칸. 이동 입력을 받는 순간 플레이어 논리 위치가 목표 칸으로 바뀐다. 120ms는 화면 애니메이션이다.
- 이동 중 입력 무시. 키를 누르고 있어도 반복 이동하지 않는다.
- 벽 충돌은 R1 대상이며 상세와 맵은 R1에서 확정한다.
- 플레이어 논리 위치가 등불 칸이 되는 순간 즉시 점등한다.
- 플레이어와 유령의 논리 위치가 같아지거나, 같은 갱신에서 서로 자리를 교환하면 즉시 실패한다. 시각적 위치로 판정하지 않는다.
- 같은 갱신에 마지막 점등과 유령 충돌 또는 시간 0초가 겹치면 실패가 클리어보다 우선한다.
### 유령·레벨
- 고정 직선 경로를 400ms마다 한 칸 왕복. 끝에 닿으면 반대 방향으로 돌아선다. 벽 통과·플레이어 추적 없음.
- 레벨 1/2/3: 등불 5/7/9개, 유령 1/2/3마리, 제한 시간 60/75/90초.
- 레벨 선택 없이 1→2→3. 모든 등불 점등 즉시 클리어, 등대로 돌아갈 필요 없음.
- 레벨 1·2의 클리어 화면에서 Enter를 누르면 다음 레벨. 레벨 3 클리어는 최종 화면으로 이어진다.
- 남은 시간이 0이 되면 실패. 실패 화면에서 Enter를 누르면 타이틀 복귀 및 점수 0 초기화.
### 점수
- 기록용이며 승패에 영향 없음. 등불 하나를 새로 켜면 100점.
- 클리어 보너스는 floor(남은 시간의 초 단위 값) × 10점. 점수는 레벨 1→3 동안 누적.
- 최고 점수 저장은 R3이며 기술·비교 시점·오류 처리 등 상세는 아직 미정.

### 문자 격자 규칙
`#` 벽, `.` 바닥, `P` 시작점, `L` 등불, `a`/`b`/`c`는 서로 다른 유령의 직선 경로다. 경로는 바닥처럼 통행 가능하고 화면에 표시하지 않는다. 가로 경로는 맨 왼쪽 칸에서 오른쪽, 세로 경로는 맨 위 칸에서 아래로 시작한다.
구체 배치는 미확정이다. 인터뷰에서 제안한 3개 격자는 참고안이며 승인된 맵 데이터가 아니다. 기획서 본문이나 src/levels.js에 확정 맵으로 복사하지 않는다.
